# QuillDNS visual identity

The canonical `quilldns-mark.svg` and `quilldns-wordmark.svg` are original SVG brand assets maintained with the source. The mark combines a stylized quill (configurable DNS records) with an open orbital arc (routing and resolution). The gradient progresses from cyan to blue to violet, emphasizing speed, clarity, and control.

- The README displays `assets/brand/quilldns-wordmark.svg` for a crisp, dark/light-mode-compatible identity.
- The Vue SPA serves `web/public/brand/quilldns-mark.svg` as both its sidebar mark and browser favicon.
- Keep both icons visually synchronized when adjusting the mark. Do not replace the brand asset with screenshots, generated interface mockups, or unicode symbols.
- SVG artwork ships without external font, image, or script dependencies. The wordmark uses widely available fallback system fonts.
